# Rust `itertools` Reference Guide

The `itertools` crate extends the standard `Iterator` trait by adding custom **Iterator Adapters** (lazy transformations) and **Consuming Adapters** (terminal operations, free functions, and collectors).

---

## 1. Iterator Adapters (Lazy)

Adapters extend standard iterators to transform, chunk, zip, or filter elements on demand.

### Grouping, Chunking & Windows

* **`chunk_by(predicate)`**: Groups consecutive elements together as long as the binary predicate returns `true`.
* **`chunks(n)`**: Yields non-overlapping chunks of fixed size `n` as mini-iterators.
* **`tuples()`**: Yields elements in fixed-size tuples (e.g., `(A, B)` or `(A, B, C)`), discarding incomplete trailing elements.
* **`tuple_windows()`**: Yields a sliding window of elements as fixed-size tuples (e.g., `(a, b)`, `(b, c)`, `(c, d)`).
* **`sliding_window(n)`**: Yields a sliding window of length `n` moving through elements one item at a time.

### Zipping, Merging & Interleaving

* **`zip_eq(other)`**: Zips two iterators together, panicking at runtime if they do not have the exact same length.
* **`zip_longest(other)`**: Zips two iterators until **both** are exhausted, yielding an `EitherOrBoth<A, B>` enum.
* **`cartesian_product(other)`**: Computes the full Cartesian cross-product of two iterators, yielding every combination pair `(A, B)`.
* **`interleave(other)`**: Alternates yielding items between two iterators until both are finished.
* **`interleave_shortest(other)`**: Alternates items between two iterators until the shorter iterator runs out.
* **`merge(other)`**: Merges two pre-sorted iterators into a single linearly sorted sequence.
* **`merge_by(other, f)`**: Merges two pre-sorted iterators using a custom ordering closure.
* **`kmerge()`**: Merges an iterator of multiple pre-sorted iterators into a single linearly sorted sequence.

### Sorting & Deduplication (Lazy / Semi-Lazy)

* **`sorted()`**: Collects, sorts in ascending order, and streams out the elements as an iterator.
* **`sorted_by(f)`**: Collects, sorts using a custom comparator function, and streams out elements as an iterator.
* **`sorted_by_key(f)`**: Collects, sorts using a key-extraction closure, and streams out elements as an iterator.
* **`unique()`**: Filters out duplicate elements across the entire stream, keeping only unique items (requires `Hash + Eq`).
* **`unique_by(f)`**: Keeps items that produce unique keys via a key-extraction closure `f`.
* **`dedup()`**: Eliminates consecutive identical duplicates (similar to `unique`, but only checks adjacent items).
* **`dedup_by(f)`**: Eliminates consecutive duplicates based on a binary predicate closure.

### Filtering, Mapping & Selection

* **`filter_map_ok(f)`**: Filters and unwraps `Result::Ok` values while discarding `Result::Err` items.
* **`map_into()`**: Converts each item using `Into::into`.
* **`map_ok(f)`**: Maps a transformation closure specifically over `Result::Ok` values, leaving `Result::Err` untouched.
* **`positions(predicate)`**: Yields the index positions of all elements matching a given boolean condition.
* **`pad_using(min_len, f)`**: Pads the end of an iterator with values generated by closure `f` until it reaches `min_len`.
* **`with_position()`**: Wraps items in a `Position` enum indicating if an element is `First`, `Middle`, `Last`, or `Only`.

### Multi-Item Lookahead & Mutation

* **`multipeek()`**: Extends `.peekable()` to allow arbitrary multi-step lookahead using repeated `.peek()` calls.
* **`peek_nth(n)`**: Allows direct lookahead to the $n$-th upcoming element without consuming items.
* **`update(f)`**: Mutates each element in-place using a closure before yielding it along the chain.

### Combinatorics (Lazy Iteration)

* **`combinations(k)`**: Yields all $k$-length combinations without repetition.
* **`combinations_with_replacement(k)`**: Yields all $k$-length combinations allowing element repetition.
* **`permutations(k)`**: Yields all $k$-length ordered permutations.
* **`powerset()`**: Yields all possible subsets (the power set) of the iterator's elements.

## 2. Consuming Adapters & Terminal Operations

Consumers evaluate the iterator pipeline to produce scalar values, formatted strings, or collections.

### Formatting & Concatenation

* **`join(separator)`**: Concatenates all elements into a single `String`, separated by a delimiter string.
* **`format(separator)`**: Creates a lazy formatting object that formats items using `Display` with zero extra allocations.

### Partial Sorting & Extremes

* **`k_smallest(k)`**: Finds and returns the $k$ smallest elements in a `Vec` without fully sorting the rest.
* **`k_largest(k)`**: Finds and returns the $k$ largest elements in a `Vec` without fully sorting the rest.
* **`minmax()`**: Computes both the minimum and maximum elements in a single pass, returning a `MinMaxResult` enum.
* **`minmax_by(f)` / `minmax_by_key(f)**`: Finds both minimum and maximum elements using custom comparator or key closures.

### Collection & Unzipping

* **`collect_vec()`**: Shortcut for `.collect::<Vec<_>>()`, eliminating the need for turbofish type hints.
* **`collect_tuple()`**: Collects a fixed number of items directly into a Option-wrapped tuple (e.g., `Option<(A, B, C)>`).
* **`into_group_map()`**: Collects key-value tuple pairs `(K, V)` into a `HashMap<K, Vec<V>>`, grouping values by key.
* **`into_group_map_by(f)`**: Groups elements into a `HashMap<K, Vec<V>>` using a key-extraction closure `f`.
* **`into_group_map_by_key(f)`**: Groups elements into a `HashMap` while transforming values concurrently.
* **`partition_result()`**: Splits an iterator of `Result<T, E>` into two separate collections: `(Vec<T>, Vec<E>)`.

### Unfolding & Construction (Free Functions)

* **`itertools::iterate(initial, f)`**: Generates an infinite sequence starting at `initial` where each item is derived from `f(previous)`.
* **`itertools::unfold(initial_state, f)`**: Creates an iterator maintaining mutable state, yielding items generated by closure `f`.
* **`itertools::repeat_n(element, n)`**: Creates an iterator that repeats a cloned element exactly `n` times.
* **`itertools::cons_tuples(iter)`**: Flattens nested tuples `((A, B), C)` into flat tuples `(A, B, C)`.
